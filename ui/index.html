🤝 共创模式 · 你出主意，AI 逐章

      
以你的想法为主：一次只写一章，AI 帮你出主意、按你的要求写，你审完满意再写下一章——AI 不自作主张改方向，从根上治“越写越变形”。人物关系与逻辑由你把控，AI 不需要额外记忆。需 claude 或 codex。

      

        
        下一章：第 ? 章
      


      

        💡 想让 AI 出什么主意？（可选：这一章怎么走 / 某场景怎么写 / 人物怎么反应 / 帮我搭接下来几章）
        
      

      

        
        
      

      


      

        ✍️ 本章我的要求（人物、情节、走向、结尾——你说了算，写得越具体 AI 越不跑偏）
        
      

      
      

        
        
        
        
      

      

      

    

  


  

    

      
      
🔍 复检

      
让 AI 复核并修正已写内容：逻辑/设定矛盾就地改、文风就地润色、故事合理性给方案、节奏/格局给前瞻提速方案。不改范围外章节、不新增后续章。

♻️ 重写

      
【推倒重写】不是润色。开始前会自动 git 存档，不满意可在书目录 git reset --hard 回退。写作中需先停止。

      
      
      
      

      

    

  


  
  

    

      
      
📤 发布到番茄

      
通过已登录的 Unzoo 浏览器驱动番茄作者后台。只发番茄还没有的新章（按全书章号去重，绝不重发）；重写过的旧章用「同步重写章」找番茄对应章覆盖。定时发布由番茄侧排程，建卷不可逆——默认不按卷、只追加发，零风险。

      

        
        
        
        
        
        
      

      
      
      
      
      

        
        
      

      

        📕 在番茄创建新作品（本地书还没上番茄时用）
        
本地书还没在番茄建过时用。自动带入：书名=本书名、简介=下方「作品简介」（需 50–500 字）。你选频道+主分类、可填主角名，点创建——会在你番茄账号真实建一本新书（不可逆），成功后自动回填上方「番茄书籍」的 bookId。主分类签约后不可改，男/女频分类不同。

        

          
          
          
          
        

        

        

      

      

        📚 番茄卷管理（改卷名）
        
番茄「第N卷：」序号自动生成、卷不可删——这里只改副标题（≤16字）。改名走已登录浏览器，约 10 秒/次。

        

        

      

      

      

        
        
        
        
      

      

    

  


  
  

    

      
      
📥 从番茄导入图书到本地

      
通过已登录的 Unzoo 浏览器，把番茄上的整本书（卷结构 + 全部章节正文）拉到本地。导入后这本书就和本地书一样可用——完结收口、完本感言、发布对账都能在 app 里直接跑。常用于番茄独有、本地没有正文的书。

      

        
        
      

      
      

        
      

      

      

        
        
        
      

      

    

  


  
  

    

      
      
✏️ 改书名

      
改名会全书生效：更新设定圣经、章节索引、连贯性台账、各卷大纲、简介与三模型上下文里的《书名》。已写正文不变（正文里本就不含书名）。封面上的书名文字需重新生成封面才更新。写作中需先停止。

      
      

        
        
      

      

    

  


  
  

    

      
      
🏁 完本策略

      
收尾冲刺：autopilot 改发"收束令"，逼向大高潮+结局、对照台账逐条回收伏笔、给人物结局。作者收完输出「【完本待审】」后，主编核对完本清单（主线/伏笔/人物/卖点/有无烂尾），通过才标"已完本"并干净停止；不过则退回补写。

      

      

        
        
        
        
        
      

      
完结收口（内部完本 → 番茄平台完结）：把收尾新增章发齐到番茄、对账平台状态。番茄签约/征文书完结需编辑审批，软件不替你按下不可逆的提交。

      

        
        
        
      

      

      

      

        

        

      

    

  


  
  

    

      
      
📋 大纲审稿

      
换另一个模型当主编，按节奏/格局/爽点/逻辑/伏笔/规模审你的大纲，给出【硬伤/隐患/建议】分档意见，写入 reviews/大纲审稿-xxx.md。意见只供作者参考修订，不直接改大纲。

      
      
      

        
        
      

      

      

        

        

        

      

    

  


  
  

    

      
      
🎨 文风

      
选一个文风，或让 AI 据本书题材推荐。改完会重写本书写作规范，下次写作即生效（已写章节不变）。

🧭 本卷共创大纲

      
全书只有粗罗盘（每卷一句话走向）。写一卷之前，先跟 AI 把这一卷的章级大纲定下来——AI 据罗盘出草案，你随便改（加减章、改走向、改钩子），存了再写这一卷。每卷你亲自把关，故事就不会"看着完整实则跑偏"。

      

        
        
        
        
      

      
      

        
        
      

      

    

  


  
  

    

      
      
🖼️ 生成封面

      

        

          
          
          
          

            
            
            
Google Imagen 出竖版底图，约 10–20 秒（需 Gemini key + 代理）。

          

          

            
            
            
            
复用已登录的 ChatGPT（Pro）网页生图，免费但慢（约 2–4 分钟）。提示词同上。若生成超时/没自动拿到，但你在浏览器里已看到图成了 → 点「📥 抓取封面」直接从当前页把图抓下来。

          

          
封面 600×800 → 书目录 cover.png。

          

            

              
              
            

            
把已保存的 cover.png 推到番茄「作品信息」。默认停在"待提交"让你去浏览器点"立即修改"确认；勾「全自动提交」则一步到位。需先在发布里配好该书的番茄账号+书籍。

          

          

            
            
          

          

        

        

      

    

  


  
  

    

      
      
删除这本书？

      

      
      
不勾选则只从书架移除、保留磁盘文件。

      

        
        
      

      

    

  


  
  

    

      
      
🧪 书名实验生成器

      
为  批量生成【多个候选书名】+ 每个配一张不同画面的封面底图，供番茄「多书名实验 / 多封面推荐」配实验用。
书名由 AI 按设定出（各打不同读者钩子），封面由 Imagen 逐张出（约 15 秒/张）。生成后可「🚀 推到番茄」：自动切到该书、逐个填书名(别名)+上传封面（封面上传已全自动）。
⚠️ 番茄多书名实验门槛：20万字+ / 已签约 / 未完结，且该里程碑实验未跑过。不满足时会把页面打开、候选列出来，让你手动配。
